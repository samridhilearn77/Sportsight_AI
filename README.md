
# 🏅 SportsSight AI

**AI-powered sports performance analysis for athletes.**

SportsSight AI aims to help athletes, especially in rural areas, improve their performance through video-based movement analysis and personalized feedback.

## ✨ Features
- Athlete profile and sport selection
- Sports video recording and upload
- AI-based posture and technique analysis
- Performance feedback reports
- Support for Wrestling, Running, and Kabaddi

## 🛠️ Tech Stack
- Flutter & Dart
- Python & FastAPI
- OpenCV & MediaPipe
- Firebase

## 🎯 Goal
Making sports performance analysis accessible to every athlete through AI-powered feedback.
